Data Searches for MapInfo User Guide
===================================

User guide for [Data Searches for MapInfo](https://github.com/LERCAutomation/DataSearches-MapInfo), covering version 1.4.47.

The guide includes configuration examples, operating instructions and a release change log. It is published in HTML and PDF on [Read the Docs](https://readthedocs.org/projects/datasearches-userguide/).

A separate [ArcGIS Pro tool](https://github.com/LERCAutomation/DataSearches-ArcPro) and [user guide](https://readthedocs.org/projects/datasearches-arcpro-userguide/) are available.

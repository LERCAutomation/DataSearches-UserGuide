Data Searches for MapInfo User Guide
===================================

User guide for [Data Searches for MapInfo](https://github.com/LERCAutomation/DataSearches-MapInfo), covering the release recorded in [conf.py](conf.py).

The guide includes a quick start and worked example, configuration examples, operating instructions and a release change log. It is published in HTML and PDF on [Read the Docs](https://readthedocs.org/projects/datasearches-userguide/).

A separate [ArcGIS Pro tool](https://github.com/LERCAutomation/DataSearches-ArcPro) and [user guide](https://readthedocs.org/projects/datasearches-arcpro-userguide/) are available.
